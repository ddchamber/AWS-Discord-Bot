AWS Discord Bot Deployment Checklist
====================================

1) Launch EC2 Instance
   ─────────────────────
   • In AWS Console → EC2 → Launch Instance  
   • Region: us‑east‑1 (or any Bedrock‑supported region)  
   • AMI: Amazon Linux 2023 or Ubuntu 22.04 LTS  
   • Instance type: t2.micro (free tier)  
   • Security group: allow SSH (22) and Discord bot ports (if any)  

2) Attach IAM Role
   ─────────────────
   • In AWS Console → IAM → Roles → Create role → EC2  
   • Attach managed policy: AmazonBedrockFullAccess  
     (or custom policy allowing “bedrock:InvokeModel” and “bedrock:ListFoundationModels”)  
   • Apply role to your EC2:  
     EC2 → Select instance → Actions → Security → Modify IAM Role → Choose new role  

3) SSH & Prepare Environment
   ────────────────────────────
   $ ssh -i key.pem ec2-user@<EC2_PUBLIC_IP>  
   $ sudo yum update -y       # or sudo apt update  
   $ sudo yum install git python3 -y  # or apt install git python3-venv  

4) Clone Repo & Install Dependencies
   ───────────────────────────────────
   $ git clone https://github.com/yourusername/AWS-Discord-Bot.git  
   $ cd AWS-Discord-Bot  
   $ python3 -m venv botenv  
   $ source botenv/bin/activate  
   $ pip install -r requirements.txt  

5) Create & Configure `.env`
   ───────────────────────────
   • In project root create `.env` with:  
     DISCORD_TOKEN=your_discord_bot_token_here  
     AWS_DEFAULT_REGION=us‑east‑1  
   • **Do NOT** set AWS_ACCESS_KEY_ID or AWS_SECRET_ACCESS_KEY  
     (so boto3 falls back to the EC2 role)  

6) Enable Bedrock Models
   ─────────────────────────
   1. In AWS Console → Amazon Bedrock → Model access  
   2. Click Modify model access  
   3. Toggle on each required model:  
      – anthropic.claude-3-haiku-20240307-v1:0  
      – amazon.titan-embed-text-v2:0  
   4. Save changes (propagation takes <1 minute)  

7) (Optional) Verify Access
   ──────────────────────────
   Create `list_models.py`:
     from dotenv import load_dotenv  
     import os, boto3  

     load_dotenv()  
     region = os.getenv("AWS_DEFAULT_REGION")  
     print("Region:", region)  

     sts = boto3.client("sts", region_name=region)  
     print("Caller ARN:", sts.get_caller_identity()["Arn"])  

     bedrock = boto3.client("bedrock", region_name=region)  
     for m in bedrock.list_foundation_models()["modelSummaries"]:  
         if m["modelId"] in (  
             "anthropic.claude-3-haiku-20240307-v1:0",  
             "amazon.titan-embed-text-v2:0"  
         ):  
             print("✅", m["modelId"])  

   Run:  
     $ source botenv/bin/activate  
     $ python3 list_models.py  

8) Configure & Start systemd Service
   ──────────────────────────────────
   • Ensure `/etc/systemd/system/discordbot.service` has:  
     ExecStart=/home/ec2-user/AWS-Discord-Bot/botenv/bin/python3 /home/ec2-user/AWS-Discord-Bot/bot.py  

   $ sudo systemctl daemon-reload  
   $ sudo systemctl enable discordbot  
   $ sudo systemctl start discordbot  
   $ sudo systemctl status discordbot  

9) Monitor & Test
   ─────────────────
   $ journalctl -u discordbot -f  
   • Watch for “Using AWS identity:” and no AccessDeniedException  
   • Send a message to your Discord channel; bot should respond  

— End of Checklist —
